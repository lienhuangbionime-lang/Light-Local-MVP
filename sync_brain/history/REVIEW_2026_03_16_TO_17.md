# Development Review & Reflection (2026-03-16 ~ 03-17)

## 1. Technical Error Analysis

### 1.1 AI Secretary "Parsing Failed"
- **Incident**: The AI Secretary consistently returned "AI 解析失敗，請再試一次".
- **Root Cause**: Reliance on `gemma-3-27b-it`. This model showed instability in delivering consistent JSON-only responses or was unreachable in the specific environment.
- **Resolution**: Switched to `gemini-1.5-flash`.
- **Reflection**: In production environments requiring high reliability and structured data, **Gemini 1.5 Flash** remains the superior choice due to its speed and JSON-mode stability.

### 1.2 Webhook "A+1" No Response
- **Incident**: Standard commands like "A+1" generated no response and no visible logs in some cases.
- **Root Cause**: `NameError: name 'CURRENT_PAGE_ID' is not defined`. 
- **The Blind Spot**: 該變數以往只在 `/api/health` 執行後才會從 FB API 獲取並寫入，但 Webhook 處理流程中直接引用了它。若伺服器重啟後，健康檢查尚未執行，Webhook 就會崩潰。
- **Resolution**: 
    1. 在 `main.py` 最頂層顯式初始化 `CURRENT_PAGE_ID: str = ""`。
    2. 在健康檢查中加入 `global` 聲明確保全域生效。
- **Reflection**: **State Initialization Drift**. Mission-critical variables must have a clear boot-time guarantee. Defensive coding should always check for variable existence or use a getter.

## 2. Architectural Breakthroughs

### 2.1 Admin-Triggered Orders (Inbox Control)
- **Concept**: Instead of waiting for a Customer to type "A+1", the Admin (Seller) can now type "A+1" in the Messenger Inbox to a Customer.
- **Impact**: Bridges the gap between manual negotiation and automated checkout. The Seller controls the conversion rate by proactively pushing the link.

### 2.2 Checkout AI Photo-Fill (Vision as Input)
- **Concept**: A "📸 AI 圖片填單" button on the checkout page.
- **Logic**: Users upload a screenshot (address or profile), and AI pre-fills the form.
- **Impact**: Reduces mobile friction to nearly zero. This is a critical edge in the Local-First MVP.

## 3. Lessons for Future AI Sessions

> [!IMPORTANT]
> **Variable Lifecycle**: Pay extreme attention to the lifecycle of global variables. If a variable is populated via an API call, it needs a fallback or a boot-time fetch.
> **Prompt Engineering**: When using AI for extraction, keep the prompt as a "Strict JSON Agent" to avoid conversational filler that breaks `json.loads()`.
