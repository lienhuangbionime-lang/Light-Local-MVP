## 🔍 根本問題分析

這三天的工作圍繞一個核心問題演化：

> **「本地端與雲端之間的狀態不一致，導致訂單遺失和連線不穩定。」**

問題根源鏈如下：

```
本地設置商品代號 D
  → 但雲端 Webhook 不知道 D 是什麼
    → 留言 D+1 被拒絕 / 忽略
      → 客人收不到結帳連結
        → 伺服器重啟後舊訂單 404
          → 信任崩潰
```

## 🛠️ 後續解決方案（行動清單）

### 🔴 優先級 P1 — 必須立即完成

#### A. 取得永久 FB Page Access Token
目前的 Token 可能幾小時就失效。請按以下步驟操作：

1. 開啟 [Meta Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. 在 Permissions 區塊勾選以下 4 項：
   - `pages_show_list`
   - `pages_messaging`
   - `pages_read_engagement`
   - `pages_manage_metadata`
3. 點擊 `Generate Access Token` → 取得 User Token
4. 搜尋列改輸入 `me/accounts` 並提交
5. 找到粉專，複製其頁面專屬的 `access_token`（此 Token 通常**永久有效**）
6. 貼回系統網頁完成更新

#### B. 確認 FB App 進階存取權 (Advanced Access)
- 至 Meta Dashboard → App Review → Permissions and Features
- **`pages_read_user_content`** 必須是綠色的「進階存取權」
- 修改後在系統網頁點擊「🔗 重新綁定粉專事件」
