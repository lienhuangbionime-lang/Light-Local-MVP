# AI Agent Guidance Reflection: 2026-03-17 📘

## 🎯 Guidance Summary
Today's session was characterized by a transition from "Functional Hacking" to "Professional Engineering." The USER provided high-level architectural guidance to stabilize the system for 24/7 cloud operation.

---

## 🏗️ 1. Backend Modularization (Structural Guidance)
- **Problem**: A monolithic `main.py` was difficult to maintain and caused deployment "Variable Drift."
- **Guidance**: Refactor into a standard Python package structure.
- **Implemented**:  
  - `core/`: Security and shared utilities.
  - `database/`: Firebase abstraction (Firestore).
  - `models/`: Pydantic schemas (Single Source of Truth).
  - `services/`: Specialized logic (AI, FB, Orders).
- **Result**: Improved code testability and faster feature isolation.

## 🧠 2. Tiered AI Intelligence (Optimization Guidance)
- **Problem**: Gemini 3.1 Pro has high intelligence but low daily quota (500). Gemma 3 has high quota (14.4k).
- **Guidance**: Use a "Receptionist vs. Executive" model.
- **Implemented**:
  - **Receptionist (Gemma 3)**: Routine Q&A, simple order triage, FAQ.
  - **Executive (Gemini 3.1)**: Complex multimodal parsing, image analysis, edge-case decision making.
- **Result**: Labor-saving at scale while maintaining cost-efficiency and intelligence.

## 🚀 3. Cloud Deployment Resilience (Self-Healing Guidance)
- **Problem**: Render deployment failed with `ModuleNotFoundError: No module named 'backend'`.
- **Guidance (Reflected)**: Focus on project root execution and dynamic path injection.
- **Correction**: 
  - Injected `sys.path` fixes at the absolute top of entry points.
  - Standardized Render Root Directory to the project root (not `backend/`).
  - Implemented dynamic `$PORT` binding for cloud compatibility.

## 🎨 4. UI Separation of Concerns (Merge/Split Strategy)
- **Problem**: The "Live" page was becoming overcrowded with inventory and settlement logic.
- **Guidance**: Move "Post-Order Management" to where it belongs.
- **Implemented**:
  - **Live Page**: Dedicated to *Stream Settings, Dictionary Sync, and Real-time Events*.
  - **Sales Page**: Dedicated to *Harvesting, Order Verification, and Inventory Deductions*.
- **Result**: Cleaner UI flow and clearer mental model for the user.

---

## 📈 Learning Point for AI Agent
> "Mission-critical state must be globally guaranteed at boot. Absolute imports from project root are more stable than relative sub-package execution in cloud environments."
